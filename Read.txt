buat kode untuk visual studio - C# project
# 1. Buat folder utama root untuk workspace Anda dan masuk ke dalamnya
mkdir src
cd src

# 2. Buat file Solution (.sln) langsung di root folder src (akan menjadi src.sln)
dotnet new sln

# 3. Buat proyek Web API (AuctionService)
dotnet new webapi -n AuctionService -f net10.0 --no-openapi --no-https --use-controllers

# 4. Buat proyek Console (AuctionClient)
dotnet new console -n AuctionClient -f net10.0

# 5. Daftarkan kedua proyek ke dalam file src.sln
dotnet sln add AuctionService/AuctionService.csproj
dotnet sln add AuctionClient/AuctionClient.csproj

# 6. Buka seluruh folder src ini langsung ke VS Code
code .

Anda hanya perlu memindahkan/membuat ulang file solution tersebut dari dalam folder src ke folder luar Carsties:
1. Tutup proyek di Rider lewat menu File > Close Solution.
2. Hapus file src.sln atau src.slnx yang ada di dalam folder Carsties/src/.
3. Buka terminal di folder utama Carsties (folder luar yang sejajar dengan src dan specs), lalu jalankan perintah:
dotnet new sln -n Carsties
dotnet sln add src/AuctionService/AuctionService.csproj

Satu-Satunya Perintah yang Harus Dihindari
Data database baru akan terhapus jika kamu menjalankan 
perintah wsl --unregister docker-desktop-data atau menekan tombol Purge data / Factory reset di dalam menu Docker Desktop.
Jangan jalankan perintah tersebut agar database kamu tetap utuh.
netsh winsock reset - reset jaringan 

docker compose stop -> mematikan container
wsl --shutdown -> memaksa mematikan container & docker (Jika hang/mutar)

1. Selesai bekerja, jalankan docker compose stop di folder proyek kamu 
(jika pakai docker compose down, pastikan tidak menambahkan -v karena -v menghapus volume database).
2. Klik kanan ikon paus di pojok kanan bawah taskbar -> pilih Quit Docker Desktop.
3. Baru matikan (Shut down) laptop kamu
